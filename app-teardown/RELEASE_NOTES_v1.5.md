# v1.5 更新日志

> 2026-11-18 · 从「能拍能写」到「结构可对账、数据可核对、产出可分发」

## 三个重点

### 1. 页面拆到区块级

每个页面不再是一句散文，而是「定位 + 3–6 个区块」：

| 位置 | 序 | 区块 | 类型 | 内容组成 | 交互去向 | 状态 |
|---|---|---|---|---|---|---|
| center | 2 | 卡片墙 | list | 11 张（6 平台 + 5 游戏），带免费角标 | 点卡进详情 / 拖拽 / 删除 | 已确认 |
| top | 3 | 筛选 / 排序 | nav | 确认没有 | — | 确认没有 |

- 四态置信度：`已确认 / 确认没有 / 推断 / 未查`，「没有」和「没查」不再混为一谈。
- 跨页重复的顶栏、右栏、底部卡抽成**全局壳层**，只写一次，页面引用。
- 类型固定 9 类：`nav / hero / list / detail / pay / ops / tool / form / status`，可统计。

### 2. 新增第三方数据（七麦 / 点点）

五列表格：指标 / 数值 / 时间 / 来源 / 性质。

- 渠道公开的下载量、评分直接引用；
- DAU / MAU / 榜单排名标为**第三方估算**，付费墙拿不到就写「未获取」，不引用二手转述。

### 3. 产品判断固定三小节

1. 主要功能
2. 商业变现
3. 活动运营

每节可写 3–5 条，不再写「竞品是谁」「心理账户」这类推测。

## 其他改进

- 一次产出五种文件：桌面 HTML、手机 HTML、Markdown、单文件 Markdown、飞书版。
- 桌面区块表 + 手机卡片两种渲染；手机版图片按 760px 重压，体积约桌面版一半。
- `verify_report.py` 新增检查：定位/区块表数量、区块行数、absent/unknown 统计。
- `examples/etalien-pc.json` 换成真实项目数据：17 页 / 71 区块 / 8 处「确认没有」/ 4 处「未查」。

## 兼容性

- 旧数据仍可用：没有 `blocks` 的页面按原来的 `desc + points` 渲染。
- 新增字段全部可选，不影响已有报告。

## 从 1.0 到 1.5 的差别

| 维度 | 1.0 | 1.5 |
|---|---|---|
| 页面数据 | 4 字段，结构压在一句散文 | 定位 + 区块 + 置信度 + 壳层 |
| 外部数据 | 官网、备案、口碑、竞品价 | 增加七麦/点点的 DAU/MAU/下载/榜单 |
| 产品判断 | 自由发挥 | 固定三小节，可多条 |
| 产出 | 1 MD + 1 HTML | 5 个文件（含手机版与单文件 MD） |
| 校验 | 人工 | `verify_report.py` 自动查 |
